# Security Policy

## Reporting a vulnerability

Please use [GitHub private vulnerability reporting](https://github.com/sednalabs/mcp-toolkit-ts/security/advisories/new)
for suspected vulnerabilities. Include the affected revision, impact, reproduction steps, and any
suggested mitigation. Do not open a public issue for an undisclosed vulnerability.

Never include live credentials, access tokens, private keys, customer data, or non-public service
addresses in a report. Use minimal synthetic examples and redact identifying details.

## Supported versions

The default branch is supported during the initial source-release phase. A version support table
will be added when tagged package releases begin.
